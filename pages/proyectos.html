Mis Proyectos

En esta sección se encuentran algunos de los proyectos realizados durante mi proceso de aprendizaje en desarrollo web.

Cada proyecto representa una etapa diferente de aprendizaje, desde la construcción de una estructura HTML hasta la incorporación de estilos, layouts flexibles, CSS Grid y componentes de Bootstrap.

Proyectos realizados

Estos proyectos muestran la evolución del sitio a medida que incorporé distintas herramientas de desarrollo web.

Proyecto HTML

Primera versión del sitio personal realizada utilizando HTML5, etiquetas semánticas, navegación entre páginas y una estructura organizada.

Proyecto CSS

Evolución visual del sitio mediante colores, tipografías, fondos y estilos personalizados para construir una identidad visual propia.

Proyecto Flexbox

Incorporación de Box Model y Flexbox para organizar la navegación, las secciones y las tarjetas de forma flexible y adaptable.

Herramientas utilizadas

A lo largo de estos proyectos fui incorporando distintas herramientas y técnicas para construir sitios web cada vez más completos.

HTML5 y CSS3

HTML permite organizar semánticamente el contenido, mientras que CSS permite definir la presentación visual del sitio.

Flexbox y CSS Grid

Utilizo Flexbox para layouts unidimensionales y CSS Grid para organizar estructuras que trabajan con filas y columnas.

Bootstrap

Bootstrap permite incorporar componentes reutilizables y responsivos, complementándolos posteriormente con estilos propios.
